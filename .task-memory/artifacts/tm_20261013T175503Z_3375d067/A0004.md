## Final behavior

Expose one pure, synchronous function returning an immutable `List<SessionEvent>`. It returns an empty list for unrelated types and valid foreign sessions; otherwise it emits one event for `started`, or up to two for a terminal event:

| Native event | `ExecutionState` | `TurnOutcome` |
|---|---|---|
| `started` | `running`; clear `retryAt`, `error`, and prior `lastOutcome` | None |
| `succeeded` | `idle`; clear `retryAt` and `error`; set last outcome to succeeded | Succeeded |
| `failed` | `idle`; clear `retryAt` and `error`; set last outcome to failed with `ErrorInfo` | Failed with the same `ErrorInfo` |
| `interrupted`, reason `user`, `superseded`, or `inactivity` | `idle`; clear `retryAt` and `error`; set interrupted last outcome with the reason | Interrupted with the reason |
| `interrupted`, reason `shutdown` | `interruptedPendingResume`; clear `retryAt` and `error`; set interrupted last outcome with reason `shutdown` | None |
