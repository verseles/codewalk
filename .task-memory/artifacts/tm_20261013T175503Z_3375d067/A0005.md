### Final Behavior
V2-044A4 introduces a pure, synchronous, one-frame, state-aware projection function in `packages/harness_opencode` (exposed via `lib/harness_opencode.dart`) that projects OpenCode 2.0.22 execution lifecycle events (`session.execution.started`, `session.execution.succeeded`, `session.execution.failed`, `session.execution.interrupted`) into canonical Core `SessionEvent` objects (`ExecutionChanged` and, for terminal outcomes except `shutdown`, an `ItemUpserted` wrapping an `idle` message with a history-matching `TurnOutcome`).

Specifically:
1. **`session.execution.started`**: Transitions `ExecutionState` to running (`kind = ExecutionKind.running`, clearing `error` and `lastOutcome`), returning an `ExecutionChanged` event.
2. **`session.execution.succeeded`**: Transitions `ExecutionState` to idle/succeeded (`kind = ExecutionKind.idle`, `lastOutcome = ExecutionOutcome(kind: OutcomeKind.completed)`), clears active retry/error, returning an `ExecutionChanged` event plus an `ItemUpserted` event for the `idle` message (with `TurnOutcome` indicating completed/succeeded status matching history producer rules).
3. **`session.execution.failed`**: Transitions `ExecutionState` to idle/failed (`kind = ExecutionKind.idle`, `lastOutcome = ExecutionOutcome(kind: OutcomeKind.failed, error: ErrorInfo(...))`), returning an `ExecutionChanged` event plus an `ItemUpserted` event for the `idle` message with the error outcome.
4. **`session.execution.interrupted`**: 
   - If reason is `shutdown`: transitions `ExecutionState` to idle/interrupted (`kind = ExecutionKind.idle`, `lastOutcome = ExecutionOutcome(kind: OutcomeKind.interrupted, reason: "shutdown")`), but *does not* insert an `idle` message (matching official reference reducer: "A shutdown does not record one, since the resumed execution continues the same turn").
   - For other interrupt reasons (`user`, `superseded`, `inactivity`): transitions `ExecutionState` to idle/interrupted, and inserts an `idle` message with `TurnOutcome` indicating interrupted status.

### Edge Cases
- **Shutdown Interruption:** `session.execution.interrupted` with `reason: "shutdown"` updates execution state to idle/interrupted but suppresses `ItemUpserted` (`idle` message creation).
- **Missing / Malformed Payload:** Unrecognized event type, missing `sessionID`, malformed JSON structure, or version mismatch returns an empty list (`[]`) without throwing.
- **Privacy & Sanitization:** Native error `message` and `response.body` are sanitized according to the sibling privacy policy: raw type and message are normalized into `ErrorInfo`, stripping unselected native fields and preventing leakage of sensitive server paths or tokens.
- **Concurrent / Multiple Events:** Each event is processed purely against the passed `SessionState` without internal mutable state or side effects.
