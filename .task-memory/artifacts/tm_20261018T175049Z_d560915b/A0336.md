## Complete Results
Official AppLifecycleListener.didChangeAppLifecycleState permits resumed only after null,inactive,detached; inactive after null,hidden,resumed; hidden after null,paused,inactive; paused after null,hidden. Thus a directly simulated paused→resumed notification violates the listener contract; the ordinary reverse path is paused→hidden→inactive→resumed. Official AppLifecycleState documents synthetic hidden transitions on mobile and distinguishes inactive (visible/unfocused) from paused (not visible). This supports correcting the simulated test sequence, not weakening runtime assertions.
