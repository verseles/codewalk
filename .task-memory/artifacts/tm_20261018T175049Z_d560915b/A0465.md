# Unified Research Report
## Request and Scope
GLOBAL: Flutter nested Scrollables, wheel arbitration and axis modifiers, English computing subject, current official documentation.
## Complete Results
Pointer signals resolve after event dispatch. PointerSignalResolver invokes only the first registered callback, corresponding to the deepest interested listener. Register through Listener.onPointerSignal rather than dispatching duplicate wheel handlers. ScrollBehavior.pointerAxisModifiers swaps mouse-wheel axes while configured modifiers are held; defaults are the two Shift keys. This applies to physical mouse events, not every pointer kind. Material desktop ScrollBehavior adds vertical scrollbars, preserving an independent way to read bounded tall content. Inference: a listener inside a bounded code viewport can reserve vertical-wheel input for a known outer vertical Scrollable, while leaving modified mouse wheels and non-wheel gestures to normal Flutter handling. Direction and physics must be verified against the installed SDK and with tests.
## Agreement, Conflicts and Disambiguation
