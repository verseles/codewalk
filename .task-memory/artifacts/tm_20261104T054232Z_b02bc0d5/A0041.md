# Unified Research Report
## Request and Scope
GLOBAL: Dart Process.start directory/environment contract; English technical sources, Dart API3.13.4.
## Complete Findings
Official Process.start API accepts workingDirectory, environment, includeParentEnvironment(defaulttrue) and detached mode. workingDirectory sets child directory; on some platforms directory changes before execution, so executable/argument relative paths may be affected. If environment is unset, parent environment is inherited. Detached child survives parent and exposes only pid, no stdin/stdout/stderr or exit status. API text does not establish deleted-cwd failure behavior; that needs local reproduction.
