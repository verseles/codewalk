Verified platform facts that shape the design (official Android reference, checked for this plan):
- Silent self-update on API 31+ is legitimate: `setRequireUserAction(USER_ACTION_NOT_REQUIRED)` removes user action when the installer holds `REQUEST_INSTALL_PACKAGES`, declares `UPDATE_PACKAGES_WITHOUT_USER_ACTION`, and is "updating itself" (one of the listed accepted installer conditions). `UPDATE_PACKAGES_WITHOUT_USER_ACTION` protection level is **normal** (no runtime prompt); `POST_NOTIFICATIONS` is **dangerous** (API 33+).
- `STATUS_PENDING_USER_ACTION` means "launch the intent activity described by `Intent.EXTRA_INTENT`"; `STATUS_FAILURE_ABORTED` is a distinct terminal status (user/system aborted).
- `ACTION_MY_PACKAGE_REPLACED` is a **protected** broadcast sent only to the replaced package, so a manifest receiver with `android:exported="false"` cannot be spoofed.
