Verified public sources as of 2026-09-29: pub.dev has only flutter_mermaid 0.1.0; official GitHub repository has no tags/releases and its later commit only changes URLs/license. No supported dependency upgrade exists. Version 0.1.0 MermaidStyle has no value equality; factories return const instances but copyWith/new constructors create distinct identity. MermaidDiagram.didUpdateWidget compares style by identity and resets layout/parses again when it differs. The commit creates a new MermaidStyle every MermaidDiagramWidget build, so parent/stream updates can cause redundant parse/layout. Theme APIs are incomplete for several chart types: sequence participant labels, timeline event labels, radar/XY axis labels, and Kanban text/backgrounds contain hardcoded colors; flowchart default node/edge/edge-label, some timeline title and Gantt labels honor MermaidStyle.
