OpenChamber commit 1a566db6 uses one renderMenu contract for both dropdown and right-click context menu in packages/ui/src/components/layout/SessionTabsStrip.tsx. It preserves inactive-tab state, pointer-position context menus, keyboard/tab semantics, menu-open state, and destructive/action separation through menu primitives, but still renders conventional vertical menu items rather than icon grids. This supports preserving CodeWalk's unified action semantics while treating compact icon grouping as CodeWalk-specific client UX, not protocol behavior.
