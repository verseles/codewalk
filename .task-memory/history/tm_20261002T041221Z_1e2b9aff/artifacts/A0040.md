Pesquisa GLOBAL com Context7 /openai/codex + Brave/Google/Standard + docs oficiais e código rust-v0.160.0 confirma app-server JSON-RPC com listener ws e auth capability-token/HS256 JWT. Daemon é servidor compartilhado local UDS; proxy stdio faz ponte ao socket. TUI pode explicitamente conectar ao listener separado via codex --remote ws/wss/unix, portanto um listener dedicado pode compartilhar sessões com TUIs que apontem a ele; não se conecta automaticamente ao daemon padrão. Código 0.160 rejeita todo Origin com 403 e exige auth em non-loopback, divergindo de rolling docs que dizem auth opcional durante rollout. Remote-control é fluxo first-party pareado/relay; exec-server fornece execução/files e não API chat. WS marcado experimental e sem suporte produção pela documentação. Nenhum servidor foi iniciado.
