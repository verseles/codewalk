The frontier helper (helperClaude-opus-5-xhigh-F): fix_required, overall_risk low, confidence high. It confirms the grouping by ProjectRef (host plus location.directory) follows the 2.0.22 contract and the ADR-023 decision, the projection is pure and keeps the server's order, and the session without a project is covered. It found one real gap: the official session.moved event changes location.directory, projectID and subpath, but the catalog signal does not map it, so a session moved by another client stays in its old group until a later created/forked/renamed/deleted event or a manual refresh. Before this unit the location did not appear in the list; now it defines the group. It also suggested that the group header is only exercised in the compact left-to-right layout, so an overflow or a direction regression in right-to-left, at the 2x text scale or in the wide layout would pass the matrix.
