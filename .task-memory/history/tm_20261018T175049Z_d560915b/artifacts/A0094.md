REJECTED WITH EVIDENCE

Instead, the dialog reports the refusal accurately: it says the list is not the endpoint's current answer and the user retries, and nothing was sent.

Rejected: the transport maps every failure to a typed receipt (session_lifecycle_client.dart:454-468) and the io source catches the only pre-send refusal, the ArgumentError, so the await cannot throw.
