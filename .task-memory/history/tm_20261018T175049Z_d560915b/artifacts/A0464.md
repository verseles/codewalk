# Unified Research Report
## Request and Scope
GLOBAL: Flutter indeterminate progress accessibility roles, English computing subject, current official API documentation.
## Complete Results
SemanticsRole values map to native accessibility roles. loadingSpinner represents busy indeterminate activity; progressBar represents numeric progress. Semantics accepts a role, whose default is none. ExcludeSemantics removes the entire descendant semantics subtree: a wrapper must explicitly restore the intended role if it excludes the native indicator. A null LinearProgressIndicator value means indeterminate, while non-null means numeric progress.
