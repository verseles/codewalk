## Achados de arquitetura (materiais)
- Dio é PROIBIDO fora de `packages/codewalk_net/` e `packages/harness_*` pela regra de arquitetura (`tool/ci/architecture/manifest.dart:170`); o plano deve usar `codewalk_net`.
- `IoEndpointHttpTransport` não segue redirect e é preso a uma origem; o asset do GitHub responde 302 para `release-assets.githubusercontent.com` com query. Requer transporte por origem, allowlist HTTPS (`github.com`/`*.githubusercontent.com`), até 3 redirects.
- `open_filex.startActivity` retorna "done" após `startActivity`, não após instalar; não checa `canRequestPackageInstalls`.
- `SHA256SUMS` ao vivo: `<64 hex>  codewalk-android-arm64.apk`; a API expõe `size` e `digest` do asset (beta.1: 89.172.665 B).
- `applicationIdSuffix = ".v2preview"` em builds de preview; release é `com.verseles.codewalk` → guarda para preview não se auto-instalar.

## Arquitetura proposta
- `UpdateInstallController` (ChangeNotifier, app-scoped): máquina de estados, geração, throttle, cancelamento, auto-open só em foreground.
- `UpdatePackageDownloader`/`UpdatePackageInstaller` (interfaces puras em `lib/shared/releases/update_install.dart`).
- `GithubApkDownloader` em `lib/platform/releases/update_package_io.dart`: busca SHA256SUMS (≤64 KiB), valida tamanho+digest incremental, `.part` + rename atômico, sweeps.
- `OpenFilexUpdateInstaller` com MIME `application/vnd.android.package-archive`.
- Sem novas dependências; usa `codewalk_net`, `crypto`, `path_provider`, `open_filex`.

## Comportamento
- Verificação SHA-256 fail-closed; estados idle/downloading/verifying/readyToInstall/installerOpened/failed(kind); retry; cancel; discard; sweep no startup.
- Android nunca abre browser; Linux inalterado; beta opt-in default stable (B1-B5).
- Auto-open só em foreground; caso contrário botão Install. UI nunca diz "instalado".
- 14 ARBs + l10n geradas; `BEHAVIOR.md`; testes unit/widget/integration + matriz manual M1-M13.

## Riscos/limites
- SHA256SUMS compartilha o domínio de confiança da release; assinatura Android cobre substituição.
- Hash inline pode gerar jank em 89 MB (medir; fallback isolate).
- `.v2preview` guard é inferência (A7), sujeita a decisão do owner.
- Atualização beta.1 → build com a feature ainda cai no browser na primeira transição.
