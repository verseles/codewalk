> 📣 CodeWalk 2.11.1 fixes the Android release build that kept 2.11.0 from being published, so it is the first published 2.11 release and ships everything from 2.11.0: Flutter 3.50.1, crisp Linux high-DPI circles, smooth desktop animations and the sub-agent capsule glow.

### Build & release

- Updates the Android Gradle Plugin from 9.3.1 to 9.3.3, whose bundled lint no longer crashes on JDK 17 (`NoSuchMethodError: java.util.List.removeLast()`, Google issue 522845800). That crash failed the 2.11.0 Android release build, so 2.11.0 was never published (`#460`).

### Included from 2.11.0

- Adds a luminous sweeping border glow around the floating sub-agent and shell activity capsule whenever active sub-agents or running shells are present (`#525`).
- Replaces the indeterminate ring on in-progress task list items with a static RTL-aware double-arrow icon (`#511`).
- Restores smooth native continuous indeterminate animations across all platforms and sizes, including compact desktop rings and updater progress bars (`#510`, ADR-062).
- Upgrades the Flutter SDK from 3.47.9 to 3.50.1 (Dart 3.14.0) for crisp circles and arcs on high-DPI Linux displays, and updates the Android Gradle toolchain to Gradle 9.5.0 and KGP 2.4.20 (`#509`).
