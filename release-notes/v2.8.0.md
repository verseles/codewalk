> 📣 CodeWalk 2.8.0 refines the conversation timeline: user bubbles shrink to fit their text, context compaction becomes a quiet centered divider, and an optional tokens-per-second chip shows each finished turn's speed.

### Timeline and messages

- Shrinks user message bubbles horizontally to fit their content (`#500`), capped at `min(640, 85% of the lane)` with no wide minimum width, while keeping a 48 dp tap target and right alignment on phone and desktop.
- Renders automatic and manual context compaction as one centered hairline divider (`#520`): a spinner while it runs, **Context compacted** collapsed until tapped to reveal the summary and optional token counts, an interrupted state, and an error state with bounded, redacted details instead of a bulky "Details" card.
- Adds an optional **Tokens per second** switch to the chat's **Display** menu (`#499`, off by default). When on, each completed turn's final answer shows a discreet `tok/s` chip beside its elapsed time, in live and history views, using the official OpenCode turn formula over every step; the message details gain a Speed row. Turns still running, failed, interrupted, partially loaded, or without streaming timestamps show no rate rather than an estimate.
